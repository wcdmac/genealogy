## 第 0 章 认识软件与准备工作

### 0.1 两种使用方式

| 方式 | 程序 | 适合场景 |
|---|---|---|
| **图形界面（GUI）** | `genealogy-gui.exe` | 日常录入、看树、查关系、排版预览；鼠标操作，所见即所得 |
| **命令行（CLI）** | `genea.exe` | 批量导入、脚本化处理、导出打印、CI 校验；精确可控 |

两者操作**同一个 `.db` 文件**，数据完全互通。推荐组合：**GUI 录入 + CLI 导出打印**。

### 0.2 三个阶段的心法

```
   录入              校核               出书
┌─────────┐    ┌─────────┐    ┌─────────┐
│ 人物    │    │ 关系    │    │ 谱书HTML│
│ 支派    │───▶│ 事件    │───▶│ 世系图SVG│
│ 地点    │    │ 派语    │    │ 古籍SVG │
│ 派语    │    │ 校验    │    │ 打印PDF │
└─────────┘    └─────────┘    └─────────┘
   先建骨架        再填血肉          最后成册
```

**关键原则**：先把人录进去、把关系连上，再补细节，最后才排版。关系没连好就排版，世系图会断、称谓会错。

### 0.3 您现有的家谱库

```
D:\cd\tree\.data\gaoyang-li\
├── gaoyang-li.db          高阳李氏家谱（50 人）★ 主库
├── changlin-wu.db         昌林吴氏家谱（50 人）
├── trial.db               李氏试录本（50 人）
├── gaoyang_full.ged       高阳李氏 GEDCOM 交换文件
├── wu_full.ged            吴氏 GEDCOM 交换文件
├── 转录台账.md            扫描件转录工作台账
├── backup-76-20261121-2021/   备份
├── backup-pre-dedup/           去重前备份
└── backup-pre-migration/       迁移前备份
```

> ⚠️ 仓库 `genealogy\.data\scratch\` 下的 `.db` 都是**测试库**，不是您的数据，别选错。

### 0.4 开始前的两条纪律

1. **先备份再改**：`genea --db <库> db backup --out <目录>`（详见第 9 章）。
2. **一次只做一件事**：录入 → 校验 → 再录入，不要攒一堆错误最后排查。

## 第 1 章 建立或打开家谱库

### 1.1 GUI 打开已有库（推荐入口）

1. 双击 `genealogy-gui.exe` 启动。Windows 下**不再弹出黑色控制台窗口**。
2. 按 `Ctrl+O`，或点菜单「文件 → 打开数据库…」。
3. 弹出的文件浏览器里：
   - 顶部「当前目录」显示所在位置；
   - 点 `↑ 上级` 返回上一级，`刷新` 重新列目录；
   - 双击目录名进入，单击 `.db` 文件即把路径填入「路径」框（也支持直接手输路径）；
   - 只列出 `.db` 文件（大小写不敏感），`.txt` 等不会干扰。
4. 导航到 `D:\cd\tree\.data\gaoyang-li\`，点 `gaoyang-li.db`，再点「打开」。
5. 底部状态栏显示「已打开 …」即成功。

**启动时直接带库**（跳过选择）：

```powershell
.\genealogy-gui.exe --db "D:\cd\tree\.data\gaoyang-li\gaoyang-li.db"
```

### 1.2 CLI 新建空白库

```powershell
# 建库（自动建 schema，当前版本 v7）
.\genea.exe --db "D:\cd\tree\.data\my-family.db" db init
```

输出：`数据库就绪: ...（schema v7）`

### 1.3 从 GEDCOM 导入（如果您有别的软件导出的谱）

```powershell
.\genea.exe --db "D:\cd\tree\.data\my-family.db" io import gedcom --file "D:\cd\tree\.data\gaoyang-li\gaoyang_full.ged"
```

> 导入后**务必先校验**（第 6 章），GEDCOM 的日期/性别写法与本地口径常有差异。

## 第 2 章 录入前的三项基础设置

这三项虽然可跳过，但先设好，后面排版与统计才准确。

### 2.1 谱书基本信息（谱名、姓、郡望、堂号）

**GUI**：菜单「面板 → 谱书/世系表」相关入口；或 CLI：

```powershell
.\genea.exe --db "<库>" book update --name "李氏·高阳李氏家谱" --surname 李 --commandery 高阳 --hall "陇西堂" --note "据旧谱转录"
```

查看：

```powershell
.\genea.exe --db "<库>" book show
# 输出：李氏·高阳李氏家谱  rev=2
```

### 2.2 支派（房支）

**GUI**：「面板 → 支派管理」→ 新建，填名称/始迁祖/父房/辈字/备注。

**CLI**：

```powershell
# 建支派
.\genea.exe --db "<库>" branch add --name "长房" --gen-char "天" --note "始迁祖支"
.\genea.exe --db "<库>" branch list
.\genea.exe --db "<库>" branch show --id "<支派ID>"
```

### 2.3 地点库（先建地点，事件才能挂地点）

**GUI**：「面板 → 地点管理」→ 新建，填名称、今属地、历史沿革、经纬度。

**CLI**：

```powershell
.\genea.exe --db "<库>" place add --name "河南颍川" --type county --modern "河南许昌" --historical "颍川郡" --lat 34.2 --lng 113.5
.\genea.exe --db "<库>" place list --name 颍川
```

### 2.4 字辈派语（可选但强烈推荐）

派语是家谱的灵魂，录入后软件能自动校验「名字是否合辈分」。

**GUI**：「面板 → 字辈派语」→ 谱级派语 → 填联句 → 保存 → 一致性校验。

**CLI**：

```powershell
# 录入联句（引擎只取汉字，标点自动忽略）
.\genea.exe --db "<库>" poem set --text "天地玄黄，宇宙洪荒"
# 输出：已录入 8 个辈字  第1世 天 / 第2世 地 ...

.\genea.exe --db "<库>" poem show
.\genea.exe --db "<库>" poem check       # 校验辈字与实际世代是否一致
```

## 第 3 章 录入人物

### 3.1 GUI 录入（日常首选）

1. 菜单「文件 → 新建人物…」（`Ctrl+N`），打开「新建人物」面板。
2. 填写：姓、名（谱名）、性别、出生、卒年、字、世代、行几、支派。
3. 出生/卒年支持两种写法：
   - **公历 ISO**：`1864-05-09`；
   - **老谱原文**：`同治三年四月初四`（软件自动认年号，转成结构化日期）。
4. 保存后人物出现在「世系表」面板；在「人物卡」面板双击姓名列可再次编辑（姓/名/字/性别/世代/行几，带 rev 乐观锁）。

### 3.2 CLI 录入（批量、精确）

```powershell
# 最简：只给姓名性别
.\genea.exe --db "<库>" person add --family-name 李 --given-name 俨 --gender male

# 完整：生卒用老谱原文，带字、世代、行几、行传
.\genea.exe --db "<库>" person add `
  --family-name 李 --given-name 师孔 --gender male `
  --birth '同治三年四月初四' --death '光绪二十年' `
  --courtesy-name "孔昭" --generation 2 --birth-order 3 `
  --biography "少孤，事母以孝闻。"

# 带父亲 ID（先录父亲，拿到 ID 再录子）
.\genea.exe --db "<库>" person add --family-name 李 --given-name 某 --father "<父亲ID>"
```

输出示例：
```
已建档: 01M847Y5450004YR8BD5H25210  李老谱测试  unknown  生:同治三年 · 同治三年四月初四  rev=1
```
**记下这串 ULID**，后面建关系、画图都要用。

### 3.3 日期换算工具（核对老谱用）

```powershell
.\genea.exe date era '同治三年'        # → 1864 年（甲子年 · 鼠）
.\genea.exe date convert 1864-05-09    # → 农历 甲子年四月初四；干支 甲戌
.\genea.exe date lunar --year 1864 --month 4 --day 4
.\genea.exe date info                  # 看历法覆盖范围与口径（1368-3000）
```

> 1583 年前用「事实数据段」（1368–1582 固化历法事实），越界直接报错，绝不外推——这是为了保证老谱日期不失真。

### 3.4 查看与检索

```powershell
.\genea.exe --db "<库>" person list --limit 50
.\genea.exe --db "<库>" person show --id "<人物ID>"
.\genea.exe --db "<库>" person tree --person "<人物ID>" --depth 5
```

GUI 对应「世系表」（可筛选/排序）、「检索」面板。

## 第 4 章 建立关系：父子、夫妻、世代

**关系是本软件的核心**——称谓、五服、世系图、字辈校验全靠关系路径，而不是世代序号差。

### 4.1 父子关系

**录入时直接指定**（推荐）：

```powershell
.\genea.exe --db "<库>" person add --family-name 李 --given-name 子 --father "<父亲ID>" --mother "<母亲ID>"
```

**事后补录**：在 GUI「关系」面板操作，或用 `person name`/迁移命令。

### 4.2 夫妻关系（结合/Union）

**GUI**：「关系」面板 → 新建结合 → 选丈夫/妻子 → 保存。

**CLI**（注意：**一个 `--member` 参数，多对用逗号分隔**，不是写两个 `--member`）：

```powershell
.\genea.exe --db "<库>" union add --member "<丈夫ID>:husband,<妻子ID>:wife"
```

输出：
```
01M847XJ88000BSMFEHR3DWRM9  marriage/active  成员: ...(husband) ...(wife)  rev=1
```

多妻/续弦：

```powershell
.\genea.exe --db "<库>" union add --type concubinage --member "<夫ID>:husband,<妾ID>:concubine"
.\genea.exe --db "<库>" union add --sequence 2 --member "<夫ID>:husband,<继室ID>:wife"
.\genea.exe --db "<库>" union list --person "<人物ID>"
```

### 4.3 查关系、称谓与五服

```powershell
.\genea.exe --db "<库>" person relation <己方ID> <对方ID>
```

实测输出（夫→妻）：

```
关系路径: W
世代差: 0（同辈）
世代序号: 己 第 1 世 · 彼 第 1 世（序号差 0）
五服[ming_qing]: 齐衰杖期 一年（13 月） — 夫为妻（齐衰杖期）
称谓: 妻子（口语: 老婆；书面: 妻）
```

> **重要口径**：`世代差`由关系路径推出（上辈 -1 / 下辈 +1 / 配偶 0），是称谓与五服的依据；`世代序号`是自始祖起算的序号，只用于字辈与统计。姻亲因父母未录常会序号塌到始祖辈，**判断辈分绝不能用序号差**。

GUI 对应「关系」面板与「人物卡」的关系查询按钮。

## 第 5 章 补充事实：事件、地点、日期与证据

### 5.1 事件（生卒、 migration、科考、任职…）

**GUI**：「时间线·地点」面板看事件；录入在人物卡/事件入口。

**CLI**：

```powershell
.\genea.exe --db "<库>" event add `
  --subject-type person --subject "<人物ID>" --type migration `
  --date '光绪十年' --place "<地点ID>" --description "由颍川迁高阳"
.\genea.exe --db "<库>" event list --subject "<人物ID>"
```

事件类型：`birth|death|burial|marriage|migration|examination|office|honor|residence|annotation`

### 5.2 地点挂接

事件里的 `--place` 填第 2.3 步建的地点 ID；没有地点库的事件在时间线面板里会显示为 ID 而非地名。

### 5.3 证据链（出处与引证）

家谱讲究"言必有据"。软件用 source/citation 记录证据：

```powershell
.\genea.exe --db "<库>" source add --title "高阳李氏旧谱" --type book
.\genea.exe --db "<库>" citation add --source "<来源ID>" --subject-type person --subject "<人物ID>" --locator "卷三·第十二页"
.\genea.exe --db "<库>" citation migrate-notes   # 把旧备注批量迁成引证
```

### 5.4 文档（谱序、凡例、家训、艺文）

```powershell
.\genea.exe --db "<库>" document add --type preface --title "嘉庆四年修谱序" --content "..."
.\genea.exe --db "<库>" document search --keyword "修谱"
```

> 注意：`document` 存的是**谱书篇章正文**（谱序/凡例/族规/艺文/契约/修次说明），**不是照片附件**。照片走「照片附件」面板。

### 5.5 照片附件

GUI「照片附件」面板 → 填文件路径、类型（遗像/扫描/照片/其他）、关联人物 ID、说明 → 点「导入」。
文件按 SHA-256 去重存到库旁的 `attachments\` 目录；同一张图重复导入只存一份内容。

## 第 6 章 校验与纠错

### 6.1 全库校验（16 条规则）

```powershell
.\genea.exe --db "<库>" io validate
```

实测输出：

```
规则集 genealogy-validation v2（跑了 16/16 条）
合计: error 0 · warning 0 · info 1
[info] R16 person ... — 该事实无任何证据引用（citation 0 条）
```

- `error`：必须修，否则数据逻辑不成立（如环、性别矛盾）；
- `warning`：建议修（如缺生卒、世代冲突）；
- `info`：提示（如尚无证据引用）。

GUI 对应「校验」面板，可点开逐条看。

### 6.2 派语一致性

```powershell
.\genea.exe --db "<库>" poem check     # "辈字与世代一致，未发现冲突"
```

### 6.3 重复人物合并

GUI「重复合并」面板 → 扫描重复人物 → 列表按四级建议（强烈/可能/不建议/无法判断）与理由排序 → 选中看**并排对照**与字段冲突（红字）→ 无冲突后点「执行合并（先自动留快照）」。

> 合并会把被合并者的父子/配偶/事件/名号引用迁到保留者，再删除被合并者，并先留一份 VACUUM INTO 快照。冲突字段（父亲/母亲/字/生年）会拒绝合并，须人工核对。

## 第 7 章 排版出书：三种产物

三种产物定位不同，**可全部生成**，按需选用。

> **文件名提醒（实测）**：Windows 下 CLI 导出时，输出路径请用**英文文件名**（如 `chart.svg`、`book.html`）；中文**目录**没问题（如 `gaoyang-li/`），但中文**文件名**在部分导出命令（如 `io export chart`）上会报「写不出文件」。导出的内容里的中文（人名、图标题）不受影响。

### 7.1 谱书 HTML（最常用，打印正文）

**GUI**：「排版导出」面板 → 选标记文本/预设 → 生成 → 点「内嵌预览」看效果 → 导出。

**CLI**：

```powershell
# 三种版式：register（世系表册）/ genealogy（世系图谱）/ biography（行传）
.\genea.exe --db "<库>" io export book --template genealogy --paper a4 --out "D:\cd\tree\.data\gaoyang-book.html"

# 16K 纸张
.\genea.exe --db "<库>" io export book --template register --paper 16k --out "...\book-16k.html"
```

输出提示：
```
已导出谱书 1 人到 ...\gaoyang-book.html（32725980 字节）
在浏览器打开该文件，Ctrl+P 另存为 PDF（纸张 a4 纵向）。
```
> 文件约 32MB 是因为**内嵌了完整思源字体**（56MB 字体库按需子集化），保证任何机器打开都不缺字。若不需要可用 `--no-embed-fonts`，但会依赖系统字体。

### 7.2 世系图 SVG（六种体例）

```powershell
.\genea.exe --db "<库>" io export chart `
  --style descendant --person "<中心人物ID>" --depth 6 `
  --title "高阳李氏世系图" --out "...\chart.svg"
```

六种体例：

| style | 说明 |
|---|---|
| `pedigree` |  pedigree 法（父母上溯） |
| `descendant` |  descendant 法（子孙下延，最常用） |
| `hourglass` |  沙漏式（上下兼顾） |
| `wufu` |  五服图 |
| `european` |  欧式（横列） |
| `soviet` |  苏式（竖列，每页 `--page-size` 世） |

其他参数：`--no-spouses` 不显示配偶边，`--depth 1..30`。

### 7.3 古籍版式 SVG（竖排线装风格）

先写一个**标记文本**文件（UTF-8）：

```
〔卷〕高阳李氏家谱
〔章〕世系
〔页〕
李俨，字…
〔注〕据旧谱卷三
〔/注〕
〔圈〕李师孔
```

然后：

```powershell
.\genea.exe --db "<库>" io export layout `
  --source "...\layout-source.txt" --preset guji_classic `
  --title "高阳李氏家谱" --volume "卷一" `
  --out "...\layout.svg"
```

预设：`guji_classic`（古籍经典）/ `plain_modern`（简明现代）。多页时输出 `foo-p1.svg`、`foo-p2.svg`。

> GUI「排版导出」面板生成后可按「内嵌预览」——预览与导出消费**同一个 SVG 字符串**，像素级一致，且不需要任何光栅化依赖。

## 第 8 章 打印成册

软件本身不直接驱动打印机，采用「导出 HTML/SVG → 浏览器打印」的标准工作流（好处：纸张/边距/页眉页脚都可在浏览器里调，跨平台一致）。

### 8.1 谱书正文（HTML → PDF）

1. 用浏览器（Chrome / Edge）打开导出的 `.html`；
2. 确认中文字体正常（内嵌字体，一般不会缺字）；
3. `Ctrl+P` 打开打印对话框；
4. 设置：
   - 目标打印机 → 「另存为 PDF」；
   - 纸张 `A4`（或导出时指定的 `16K`）；
   - 方向：默认纵向（`--landscape` 导出的选横向）；
   - 边距：建议「默认」；
   - 勾选「背景图形」（否则表格线/版框可能丢失）；
5. 点「保存」，得到可送印的 PDF。

### 8.2 世系图 / 古籍版式（SVG → PDF）

1. 浏览器直接打开 `.svg`；
2. `Ctrl+P` → 另存为 PDF；
3. 纸张按图幅调整：世系图 A3/A4 横向，古籍版式 A4 纵向；
4. 若 SVG 比纸大，打印缩放选「适合页面」。

## 第 9 章 备份与恢复

### 9.1 备份（务必在做批量修改前做）

**CLI**（含附件一起打包）：

```powershell
.\genea.exe --db "<库>" db backup --out "D:\cd\tree\.data\gaoyang-li\backup-手动"
```

备份 = SQLite 官方 `VACUUM INTO` 快照，**不是文件拷贝**——直接 `cp` 活库会拷到半提交状态（WAL 未合并），恢复出来可能是坏的。

**GUI**：「备份恢复」面板 → 填目录 → 点「立即备份」。

### 9.2 恢复

**CLI**：

```powershell
# 先看备份目录里有哪些快照
dir "D:\cd\tree\.data\gaoyang-li\backup-手动"

# 恢复到目标库（默认拒绝覆盖已存在的库）
.\genea.exe --db "<目标库>" db restore --from "<备份目录>"
# 确认覆盖时：
.\genea.exe --db "<目标库>" db restore --from "<备份目录>" --force
```

**GUI**：「备份恢复」面板 → 填快照路径 → 默认拒绝覆盖；勾选确认后，旧库连同 `-wal`/`-shm` 一起移为 `.bak-<时间戳>`，任一步失败自动回滚。

> GUI 恢复会先关闭当前库连接（Windows 文件锁），恢复后自动重开。
> GUI 面板只处理主库；CLI 的 `db backup/restore` 还会一起打包 `attachments\` 附件目录。

## 常见问题

**Q：GUI 打开时一片空白 / 面板太多找不到？**
A：当前 15 个面板默认全部打开、浮动排列，可用菜单「面板」勾选显隐；拖标题栏可把常用面板并排停靠。

**Q：老谱日期"同治三年四月初四"能直接录吗？**
A：能。`person add --birth '同治三年四月初四'` 会自动识别年号。单独换算用 `genea date era '同治三年'`。1583 年前的日期走固化历法事实数据，不外推。

**Q：为什么称谓算错了（母亲 -4 辈、丈夫 +3 辈）？**
A：多半是父母没录，导致世代序号塌到始祖辈。辈分判断走关系路径（`person relation`），不要用世代序号差。

**Q：`union add` 报"未知成员角色 :wife"？**
A：写成两个 `--member` 了。正确是一个 `--member`，多对用逗号分隔：`--member "<夫ID>:husband,<妻ID>:wife"`。

**Q：谱书 HTML 有 32MB，正常吗？**
A：正常，内嵌了完整思源字体避免缺字。不需要时用 `--no-embed-fonts`，但依赖系统字体。

**Q：`io validate` 报"无任何证据引用"？**
A：这是 info 提示不是错误。用 `citation add` 挂接来源，或在转录工作台账补出处。

**Q：`io export chart` 报"写不出文件 世系图.svg"？**
A：中文文件名在部分 CLI 导出路径上的编码问题。改用英文文件名（如 `chart.svg`），中文目录和导出内容都不受影响。

**Q：恢复时提示"目标库已存在"？**
A：默认拒绝覆盖（防止用昨天盖今天）。确认要覆盖才加 `--force`，旧库会移为 `.bak-时间戳`。

**Q：照片存在哪里？**
A：库文件同级的 `attachments\<sha256>` 文件；元数据在库的 `attachment` 表。备份时用 CLI 的 `db backup` 才会一起打包。
