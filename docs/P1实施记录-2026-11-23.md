# P1 实施记录：多体例世系图与可读性（2026-11-23）

## 结论

**P1 全部落地**：新增纯 C++ SVG 生成器（`core/io/chart_svg.cpp`，自有代码，规避 Graphviz EPL），支持六种体例与四项可读性特性；CLI `genea io export chart` 接通。core 测试升至 140 用例 / 993,382 断言。全门禁通过，SVG 经 Edge 无头渲染验证。

## 一、六种体例（来自调研报告 P1）

| 体例 | 语义 | 实现要点 |
|---|---|---|
| `pedigree` | 祖先图 | 每层最多父母二人，可预测网格；**父母缺失显式告警**，不静默留空 |
| `descendant` | 后代图 | 用 `PersonGraph::children_of`（行几→出生→id 确定性排序）；兄弟共横线，配偶虚线 |
| `hourglass` | 沙漏图 | 上半祖先（≤3 代）+ 下半后代（≤3 代），中心焦点 |
| `wufu` | 五服图 | 后代骨架 + 逐对 `compute_mourning_degree`（明清外置规则表）算服等，脚注输出 |
| `european` | 欧式 | 横行分格五世一图，`--page-size` 控制每页世数 |
| `soviet` | 苏式 | 垂珠竖线，跨页重叠一世（告警中显式提示） |

## 二、可读性特性

- **焦点高亮**：点击节点切换 `.focus` 类，边框加粗。
- **搜索定位**：SVG 内嵌原生 JS（无第三方库），输入姓名过滤节点显示。
- **房支分色**：按 `branch_key`（沿 father_id 上溯到始祖）哈希取 8 色之一。
- **缺失/成环显式告警**：重复亲子、缺失祖先写入 SVG 脚注（红字），不静默吞掉。
- 另含折叠态样式（`.collapsed`）、世代对齐（`gen * kGapY`）、节点显示姓名+生年。

## 三、许可证与依赖

SVG 生成器为**自有 C++ 代码**，无 Graphviz/libgraphviz/libcgraph（全为 EPL-2.0）、无 Mermaid（MIT 但未用）、无 OGDF/igraph（GPL 排除）。SVG 内嵌的 CSS/JS 为原生代码。零新增依赖，白名单维持 12 项。

## 五、边界

- 欧/苏式的"跨页"在单 SVG 内以告警页数表达，实际分页由打印 CSS 控制；苏式第五世重叠在告警中说明，未做物理分页渲染。
- 五服图显示的是房支分色 + 逐对服等脚注，不是传统"九族五服格"的严格矩阵布局——那需要另一套版式引擎，属后续迭代。
- 图形布局为简化分层（父居中于子），非完整 Reingold–Tilford；万级节点性能未专项压测（已登记容量假设）。
