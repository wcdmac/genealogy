# genealogy 快速上手教程

> 本教程是给**第一次使用**的 5 分钟上手指南。项目随附的完整文档：
> - `docs/manual/使用手册.md`：安装、CLI 全命令、REST/Web/GUI 细节、排障
> - `docs/manual/修谱工作流.md`：从收谱到成谱的完整流程与常见坑
>
> 跑通本教程后，再按需查手册。

## 0. 这套软件由什么组成

四端共用同一套领域逻辑（core 用例层），数据都落在**同一个 SQLite 库文件**里：

- **CLI（`genea.exe`）**：脚本与批量操作首选——建库、建档、查谱、导出、备份都在这。
- **REST 服务（`genealogy-server.exe`）**：一切客户端的事实标准，47 个端点，Web / GUI / 第三方都走它。
- **Web UI（Vite + React）**：浏览器里建档、看世系图、导出。
- **桌面 GUI（`genealogy-gui.exe`）**：Dear ImGui 窗口，人物卡 / 世系表 / 检索 / 关系 / 树 / 校验面板。

> **关键认知：一个 `.db` 文件 = 一部谱。** CLI、server、GUI 都通过 `--db` 指定同一个文件，数据互通。

## 2. 第一步：建库

```powershell
cd D:\cd\tree\genealogy
.\build\bin\genea.exe db init --db family.db
```

输出：`数据库就绪: family.db（schema v<N>）`。

- 库路径可用绝对路径；不写 `--db` 时默认 `./genealogy.db`。
- 输出格式：`--format text|json`（缺省 text）。与 API / 脚本对接用 `--format json`。

## 3. 建谱四步

所有实体的 ID 是 **ULID**（26 位，形如 `01JABC...`）。下面命令里的 `01J...` / `<LINEAGE>` 都要替换成 `list` 后看到的真实 ID。

### 3.1 宗族 / 支派 / 地点（先搭框架）

```powershell
.\build\bin\genea.exe lineage add --db family.db --name "中湘陈氏六修族谱" --surname 陈 --commandery 颍川 --hall 德星堂
# 记下返回的 lineage id（下面用 <LINEAGE> 代替）

.\build\bin\genea.exe branch add --db family.db --lineage <LINEAGE> --name 东八房 --gen-char 明
.\build\bin\genea.exe place add --db family.db --name 中湘 --type county --modern "湖南省湘潭县"
```

### 3.2 建档人物（两种日期写法都支持）

```powershell
# 老谱原文照录（自动识别农历/年号，calendar=lunar）
.\build\bin\genea.exe person add --db family.db --family-name 陈 --given-name 文远 --gender male --birth "同治三年四月初四"

# 公历 ISO（自动推年干支，calendar=gregorian）
.\build\bin\genea.exe person add --db family.db --family-name 陈 --given-name 文远 --gender male --birth 1864-05-09
```

其它可选字段：`--courtesy-name 字`、`--father <ID>`、`--mother <ID>`、`--generation 世代序号`、`--birth-order 行几`、`--branch <ID>`、`--biography 行传`、`--living`（在世）。

> 不给 `--lineage` 时落入占位宗族；正式建档请显式给 `--lineage <LINEAGE>`。

### 3.3 婚姻结合与事件

```powershell
# --member 用 "人物ID:角色" 逗号分隔；角色 husband / wife
.\build\bin\genea.exe union add --db family.db --type marriage --member "<夫ID>:husband,<妻ID>:wife" --start "光绪十二年"

.\build\bin\genea.exe event add --db family.db --subject-type person --subject <人物ID> --type burial --date "光绪二十七年春" --description "葬祖茔亥山巳向"
```

### 3.4 查谱

```powershell
.\build\bin\genea.exe person list --db family.db --format json        # 列表（可 --branch / --generation 筛选）
.\build\bin\genea.exe person show --db family.db <人物ID>              # 详情
.\build\bin\genea.exe person relation --db family.db <甲ID> <乙ID>     # 路径 / 辈分差 / 五服 / 称谓
.\build\bin\genea.exe person tree <始祖ID> --db family.db --depth 10   # 十代子孙树
```

> **两个"代"别混**（设计文档 4.4.2）：`世代差`＝辈分差（称谓 / 五服依据，夫妻同辈）；`世代序号`＝自始祖第几世（字辈 / 统计用）。姻亲外亲常因父母未录断链，序号会塌到始祖辈，**不能当辈分差**。

## 4. 历法与年号（独立工具，不碰数据库）

```powershell
.\build\bin\genea.exe date info                                    # 覆盖区间与编算口径
.\build\bin\genea.exe date convert 1864-05-09                     # 公历→农历 / 干支 / 节气 / 年号
.\build\bin\genea.exe date lunar --year 2025 --month 6 --day 20 --leap   # 闰六月二十 → 2025-08-13
.\build\bin\genea.exe date terms --year 2025 --index 4             # 惊蛰 2025-03-05 16:07
.\build\bin\genea.exe date era 同治三年                            # → 1864 年（甲子·鼠），正月初一 1864-02-08
```

覆盖 **1583–3000**，1900–2025 已与紫金山天文台《1900–2025年日历》逐日核对。

> 岁首陷阱：年号元年记的是"正月所在公历年"，农历冬月 / 腊月会落到公历次年——`date era` 只解到"年"，精确到日要再过一遍 `date lunar`。

## 5. 导出 / 校验 / 迁徙

```powershell
# GEDCOM 导入（先有宗族）
.\build\bin\genea.exe io import gedcom 族谱.ged --db family.db --lineage <LINEAGE> [--surname 陈]

# 一致性校验（有 error 退出码 1，可当 CI 卡点）
.\build\bin\genea.exe io validate --db family.db

# GEDCOM 导出
.\build\bin\genea.exe io export gedcom --db family.db --out 导出.ged --submitter 谱师

# 迁徙登记
.\build\bin\genea.exe migration add --db family.db --subject-type person --subject <ID> --from <地ID> --to <地ID> --reason 营商
```

## 6. 三个界面怎么起

四端都通过 `--db` 指向**同一个** `family.db`。推荐顺序：CLI 建好数据 → 任选一个界面查看 / 再编辑。

### 6.1 REST 服务（一切客户端的事实标准）

```powershell
.\build\bin\genealogy-server.exe --db family.db --port 8080
```

- 监听 `http://127.0.0.1:8080/api/v1`，库路径见启动日志。
- **默认本地免鉴权**（只绑 127.0.0.1，仅本机可连）；对公网/局域网开放必须加 `--require-auth` 并设 `GENEALOGY_AUTH_PASSWORD`（未设口令拒绝启动），此后所有数据端点都要 Bearer 令牌。
- CORS 默认只放行本机来源（跨端口开发不受影响，第三方网页的跨站请求会被浏览器拦截）；`GENEALOGY_CORS_ORIGINS` 可显式白名单，`*` 放开。
- 错误统一 `problem+json`（RFC 9457）；写操作需带 `If-Match`（当前 rev），否则 428，版本不符 409。
- 实时协同：SSE `GET /api/v1/events/stream`，任一写操作推送 `event: change` 帧。
- spec 原样托管：`GET /openapi.yaml`。

快速试一下：

```powershell
curl -s localhost:8080/api/v1/health
curl -s -X POST localhost:8080/api/v1/persons -H "Content-Type: application/json" -d "{\"lineage_id\":\"<LINEAGE>\",\"family_name\":\"陈\",\"given_name\":\"文远\",\"gender\":\"male\"}"
```

### 6.2 Web UI（浏览器）

```powershell
cd D:\cd\tree\genealogy\clients\web
npm install            # 首次需要
npm run dev            # 开发模式，/api 自动代理到 127.0.0.1:8080
# 或生产预览（先 npm run build 产出 dist/）：npm run preview
```

打开浏览器后填服务器地址（默认同源 `/api/v1`；server 在别的端口就填 `http://127.0.0.1:8080/api/v1`）→ 连接。闭环：宗族建档 → 人物建档/编辑 → 婚姻登记 → 世系图 → GEDCOM / DOT 导出 → 校验。

> 前提：REST 服务要先在 127.0.0.1:8080 起好，Web UI 才能连上。

### 6.3 桌面 GUI（Dear ImGui）

```powershell
.\build\bin\genealogy-gui.exe --db family.db
```

- 面板（菜单「面板」开关）：人物卡（行内编辑 + rev 乐观锁）/ 世系表（可排序大表）/ 检索（FTS）/ 关系（路径+辈分+五服+称谓）/ 世系树（十代展开）/ 校验。
- 高对比度皮肤与字体缩放：`--high-contrast`、`--font-size 16`。
- 无显示环境自检：`--headless-check`（0=可用，2=无显示）。

## 7. 备份与恢复（务必养成习惯）

```powershell
.\build\bin\genea.exe db backup --db family.db --out backup/    # 一致性快照（VACUUM INTO，别直接拷活库）
.\build\bin\genea.exe db restore --db family.db --from backup/  # 恢复（目标已存在需 --force）
```

> **不要**用复制文件的方式备份正在写入的库——`db backup` 走 `VACUUM INTO` 保证一致性。完整演练脚本：`python tools/drill_backup_restore.py`。

## 8. 退出码与排障

| 退出码 | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 运行时错误 |
| 2 | 用法错误（参数不对） |
| 3 | 不存在（如 ID 查无） |
| 4 | 版本冲突（rev 不符） |

- 任何命令加 `--help` 看用法；`genea --help` 列出全部子命令。
- 想跑一遍性能验收：`genea bench --db family.db --persons 100000`（退出码 0 = 全达标，可当 CI 卡点）。
