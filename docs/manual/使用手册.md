## 1. 安装

### 1.1 用打包产物（推荐）

M6 起 CI 为三平台产出安装包（GitHub Actions artifacts）：

| 平台 | 产物 | 用法 |
|---|---|---|
| Windows | `genealogy-<版本>-Windows-AMD64.zip` | 解压即用，`bin/` 下三个 exe + 全部运行时 DLL |
| macOS | `genealogy-<版本>-Darwin-arm64.dmg` | 拖入 Applications 或直接挂载复制 |
| Linux | `genealogy-<版本>-Linux-x86_64.tar.gz` | 解压，`bin/` 加入 PATH |

本地也可自行打包（configure 后一条命令）：

```bash
cd build && cpack -G ZIP        # Windows；macOS 用 DragNDrop，Linux 用 TGZ
```

### 1.2 从源码构建

**Windows（MSVC）**——本机 PATH 有 MSYS2 32 位 g++ 会抢编译器，且 reg.exe
在安全策略黑名单（vcvars64.bat 不可用），必须用仓库脚本：

```bash
cmd /c tools\build-msvc.bat                    # core + cli
tools\build-gui-msvc.bat                       # core + cli + gui（单机三目标）
```

**macOS / Linux**：

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_TOOLCHAIN_FILE=$VCPKG_ROOT/scripts/buildsystems/vcpkg.cmake
cmake --build build
ctest --test-dir build --output-on-failure
```

可选 GUI 用 `-DBUILD_GUI=ON` 开启（manifest feature `gui` 决定依赖装不装；
overlay triplet 见 `tools/vcpkg-triplets/`）。

### 1.3 依赖

核心链路全部宽松许可（MIT / BSD / zlib / BSL / 公有领域），无 Copyleft，
可静态链接、可闭源分发。1368-1582 大统历段为固化的历法事实数据（历法不受
著作权保护），不含上游代码。白名单由 CI 卡点强制执行
（`tools/license_check.py`，含禁 Qt 检查）。

## 2. CLI 快速上手

所有命令的数据库路径用 `--db`（缺省 `./genealogy.db`），输出格式
`--format text|json`。

```bash
# 建库
./build/bin/genea db init --db family.db

# 宗族 / 支派 / 地点
./build/bin/genea book update --db family.db --name "中湘陈氏六修族谱" \
  --surname 陈 --commandery 颍川 --hall 德星堂
./build/bin/genea branch add --db family.db --name 东八房 --gen-char 明
./build/bin/genea place add --db family.db --name 中湘 --type county --modern "湖南省湘潭县"

# 人物（--lineage 缺省落入占位宗族）
./build/bin/genea person add --db family.db \
  --family-name 陈 --given-name 文远 --gender male \
  --birth "同治三年四月初四"          # 老谱原文照录，calendar=lunar
./build/bin/genea person add --db family.db \
  --family-name 陈 --given-name 文远 --gender male \
  --birth 1864-05-09                 # ISO 日期，calendar=gregorian，自动推年干支

# 婚姻结合与事件
./build/bin/genea union add --db family.db --type marriage \
  --member "01J...:husband,01K...:wife" --start "光绪十二年"
./build/bin/genea event add --db family.db --subject-type person --subject 01J... \
  --type burial --date "光绪二十七年春" --description "葬祖茔亥山巳向"

# 迁徙（M5）
./build/bin/genea migration add --db family.db --subject-type person \
  --subject 01J... --from 01P... --to 01Q... --reason 营商

# 查询
./build/bin/genea person list --db family.db --format json
./build/bin/genea person show --db family.db 01J...
./build/bin/genea person relation --db family.db 01J... 01K...   # 路径/辈分/五服/称谓
./build/bin/genea person tree <始祖ID> --db family.db --depth 10
```

> **两个"代"的口径要分清**（设计文档 4.4.2）：
> - **世代差（辈分差）** = 关系路径上的世代升降次数（上行 -1、下行 +1、配偶步不升
>   降）。夫妻同辈、妻之公公 -1。这是称谓与五服的依据。
> - **世代序号** = 自始祖起算的第几世（大宗谱法），用于字辈与统计。外亲姻亲常因
>   父母未录上溯断链，序号会塌到始祖辈，**不可**当辈分差用。

CLI 命令全貌见 `genea --help`（含 `db init|seed|backup|restore`、
`migration add|list|show|remove`、`poem set|show|check`）。

## 3. 字辈引擎

派语（字辈联句）逐字切分，定位每个人的辈字，并校验世代一致性：

```bash
./build/bin/genea poem set --db family.db \
  --text "德茂光先祖，文章振万邦"        # 每代一字，标点是分隔不是内容
./build/bin/genea poem show --db family.db
./build/bin/genea poem check --db family.db            # 退出码 1 = 有冲突
./build/bin/genea poem check --db family.db --start 2  # 派语自二世起用时
./build/bin/genea poem check --db family.db --branch 01J...  --start 7  # 按支校验（支级派语）
# 逐人核对：名中是否含本代辈字、辈字所在代是否与 generation_no 一致
# 退出码 1 = 有不一致（始祖辈取名"兴"而"兴"是派语第十句 → 当场报冲突）
```

## 4. 历法与年号工具

纯计算，不碰数据库：

```bash
./build/bin/genea date info                     # 覆盖区间与编算口径（1368-3000，1583 起有节气）
./build/bin/genea date convert 1864-05-09       # 公历→农历/干支/纪年
./build/bin/genea date lunar --year 2025 --month 6 --day 20 --leap
./build/bin/genea date terms --year 2025 --index 4    # 节气时刻（北京时间，到分）
./build/bin/genea date era 同治三年              # 年号→公历（重名年号列候选）
```

> **年号换算的岁首陷阱**：年号元年记的是「正月所在公历年」，而农历年的冬月、
> 腊月会落到公历次年——**光绪三十四年冬月初一 = 1908-11-24**（仍是光绪三十四年，
> 不在宣统）。`date era` 只解到「年」，要精确到日必须再过一遍农历引擎。

## 5. GEDCOM 导入导出与校验

```bash
./build/bin/genea book update --db family.db --name 中湘陈氏 --surname 陈   # 设置谱元数据
./build/bin/genea io import gedcom 族谱.ged --db family.db [--surname 陈]
# 导入完成: 人物 5 · 结合 2 · 事件 6 · 地点 1
# 映射损失: 1 条（warning 0 条，info 1 条）
#   [I] @S1@ SOUR — 证据引用未建模，出处链已丢失（M5 起随证据链补齐消除）

./build/bin/genea io validate --db family.db
# 合计: error 0 · warning 1 · info 2        （error 时退出码 1，可当 CI 卡点）

./build/bin/genea io export gedcom --db family.db --out 导出.ged --submitter 谱师
# 导出侧损失台账：stderr 逐条 [W]/[I]，文本摘要带损失计数，json 含 losses 字段

# 世系树导出（DOT / Mermaid，渲染与 REST /exports/tree 同一份实现）
./build/bin/genea io export tree --db family.db --person <始祖ID> --tree-format dot
./build/bin/genea io export tree --db family.db --person <始祖ID> --tree-format mermaid --out 世系.mmd

# 古籍版式导出（P2）：标记语法 + 全要素版式
./build/bin/genea io export layout --source 谱稿.txt --preset guji_classic \
    --title "陈氏族谱" --volume "卷一" --out 谱书.svg
```
标记语法（自有）：`〔卷〕〔章〕〔节〕〔注〕…〔/注〕〔批〕〔耳〕〔标〕〔圈〕〔点〕〔页〕〔indent:N〕`；
预设 `guji_classic`（全要素线装）/ `plain_modern`（素白简排）。
详见 `docs/manual/古籍版式标记语法.md`。

# 世系图导出（P1）：六种体例，纯 C++ SVG（无 Graphviz 依赖）
./build/bin/genea io export chart --db family.db --person <ID> --style pedigree --out 祖先图.svg
./build/bin/genea io export chart --db family.db --person <ID> --style descendant --out 后代图.svg
./build/bin/genea io export chart --db family.db --person <ID> --style hourglass --out 沙漏图.svg
./build/bin/genea io export chart --db family.db --person <ID> --style wufu --out 五服图.svg
./build/bin/genea io export chart --db family.db --person <ID> --style european --out 欧式.svg
./build/bin/genea io export chart --db family.db --person <ID> --style soviet --out 苏式.svg
```
`--style` 六选一：`pedigree`（祖先图，每层翻倍、空框显式暴露缺祖先）、
`descendant`（后代图，兄弟共横线、配偶虚线）、`hourglass`（上祖先下后代）、
`wufu`（五服图，逐对算服等并脚注）、`european`（横行分格五世一图）、
`soviet`（垂珠竖线，跨页重叠一世）。`--depth` 展开代数（默认 5，上限 30），
`--page-size` 每页世数（默认 5），`--no-spouses` 隐藏配偶边。

欧式/苏式为**物理分页**：多页时写出 `foo-p1.svg`、`foo-p2.svg`…（每页独立
完整 SVG，可单独打印），苏式下一页首世与上一页末世重叠一世；JSON 输出含
每页世代区间与 `overlaps_previous` 标记。五服图为**九族严格矩阵**：纵轴九族
（高祖辈～玄孙辈）、横轴五服（斩衰～缌麻），每格显示人数与代表姓名，服等
由外置规则表逐对计算。
SVG 可直接用浏览器打开：点击节点聚焦高亮，搜索框按姓名定位，房支按颜色区分；
环与断链在脚注显式列出，不静默吞掉。

# 出版谱书（P0）：生成自包含 HTML，浏览器 Ctrl+P 另存 PDF
./build/bin/genea io export book --db family.db --template register --paper a4 --out 谱书.html
./build/bin/genea io export book --db family.db --template genealogy --paper 16k --out 世系谱.html
./build/bin/genea io export book --db family.db --template biography --out 行传.html
```
`--template` 三选一：`register`（世系表，表格含世代/姓名/生卒/行几）、
`genealogy`（世系谱，竖排分世代）、`biography`（行传，含传记正文）。
`--paper` 为 `a4` 或 `16k`（线装开本），`--landscape` 切横向。
默认内嵌完整思源宋体（产物约 32MB，单文件离线可打印）；加
`--no-embed-fonts` 可生成约 2KB 的轻量版，但依赖系统字体、生僻字可能缺字。

打印步骤：用浏览器打开 HTML → Ctrl+P → 目标选「另存为 PDF」→
纸张与方向按 `--paper`/`--landscape` 设置 → 勾选「背景图形」→ 保存。
封面与派语为竖排，正文按模板排版，页脚自动页码。

随包字体：软件自带完整思源黑体/宋体 SC（OFL 1.1），位于安装目录
`bin/fonts/`，界面优先使用，避免系统字体差异与版权风险。详见该目录 README。

> 局部格式选项是 `--tree-format` 而不是 `--format`：全局 `--format`
> （text|json）在入口处先行解析，会先把子命令的 `--format dot` 吃掉。

**GEDCOM 三条硬规矩**（导入导出都守）：
- **不猜**。DATE 解不出公历（`INT 1900 (say)`、`30 FEB 1900`）就只留原文 + 记损失，
  绝不编日期；ANSEL / MacRoman 字符集直接拒收并提示先转 UTF-8。
- **损失显式化**。OBJE、SOUR、_UID、ASSO 逐条列出，谱师能看清「原文里有、库里
  没有」的到底是哪些。自家导出的文件往返零损失（测试保证）。
- **妾与继配不归并**。导出用扩展标签 `_CONC` 保留，别的软件会忽略而不是读错；
  亲子关系只认「夫妻双方齐全」的结合，孩子挂正室还是侧室是谱学判断，程序不替
  谱师决定。

## 8. 桌面 GUI

```bash
./build/bin/genealogy-gui --db family.db        # 带库启动
./build/bin/genealogy-gui --headless-check      # CI/SSH 自检：0=有显示 2=无显示
```

面板（菜单「面板」开关）：**人物卡**（行内编辑 + rev 乐观锁）/ **世系表**
（可排序大表格）/ **检索**（FTS）/ **关系**（路径 + 辈分 + 五服 + 称谓）/
**世系树**（十代展开）/ **校验**。OpenGL 3.2+ / GLSL 130，中文字体按平台探测，
高对比度皮肤 + 字体缩放。

数据层与渲染层分层：面板数据装配（DbSession + 用例层）无 ImGui 依赖，
由 `genealogy-gui-tests` 无头单测；渲染层要显示环境，CI 只验
`--headless-check`（区分「无显示环境」与「真故障」）。

## 9. 备份与恢复

```bash
# 备份：一致性快照（SQLite VACUUM INTO，不阻塞其他连接）+ 附件库随行
./build/bin/genea db backup --db family.db --out backup/

# 恢复：取备份目录里最新快照；目标已存在时拒盖（防拿昨天盖今天），
# --force 则把旧库移开为 .bak（不删除）
./build/bin/genea db restore --db family.db --from backup/
./build/bin/genea db restore --db family.db --from backup/ --force
```

**演练**（CI 每次构建都跑，退出码 0 = 通过）：

```bash
python3 tools/drill_backup_restore.py
# 灌 500 人合成谱 → 备份 → 删库（模拟误删/磁盘事故）→ 恢复 →
# 核对人物数/schema 一致 → 验 --force 保护（拒盖 + .bak 留存）
```

**备份策略建议**：每次修谱会话结束 `backup` 一次（时间戳文件名，天然多版本）；
导入大批量数据前必备份；备份目录同步到另一块盘/机器——本地快照治不了磁盘故障。

## 10. 退出码与排障

| 码 | 含义 | 常见原因 |
|---|---|---|
| 0 | 成功 | — |
| 1 | 运行时错误 | 库损坏、外键失败、备份目标不可写 |
| 2 | 用法错误 | 缺必填参数 |
| 3 | 不存在 | 人物/宗族/地点 ID 找不到 |
| 4 | 冲突 | 版本冲突（If-Match 不符）、恢复目标已存在 |

排障速查：

| 症状 | 原因与处理 |
|---|---|
| `打不开数据库` | 路径不存在且父目录不可写；或用 `db init` 显式建库 |
| 版本冲突 | 实体在别处被改过（本地乐观锁 rev 不符）；重新 `person show` 拿新 rev 再改 |
| 日期规则不报 | 时间类规则只认公历年份；农历原文换算不出公历就跳过（R12 单独提示），**宁可少报不可误报** |
| 中文乱码 | 终端需 UTF-8；源码与库均为 UTF-8，MSVC 已全局 `/utf-8` |
| GEDCOM 导入拒收 | ANSEL/MacRoman 字符集，先转 UTF-8 再导入 |
