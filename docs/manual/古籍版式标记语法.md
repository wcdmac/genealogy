# 古籍版式标记语法与使用

P2 新增的两项能力：**自有标记语法**（正文与排版指令同处一地）与**古籍版式要素参数化**（版心/鱼尾/象鼻/栏线/书耳/界行/天头地脚）。命令：

```bash
genea io export layout --source 谱稿.txt --preset guji_classic \
    --title "陈氏族谱" --volume "卷一" --out 谱书.svg
```

`--source` 为标记文本；`--preset` 二选一：`guji_classic`（全要素线装格式）、
`plain_modern`（素白简排，仅保留竖排与版心）。多页时输出 `foo-p1.svg`、
`foo-p2.svg`。SVG 可直接用浏览器打开、Ctrl+P 另存 PDF。

## 标记语法（本项目自有，中文全角 〔〕）

| 标记 | 含义 |
|---|---|
| `〔卷〕文本` | 卷标题 |
| `〔章〕文本` | 章标题 |
| `〔节〕文本` | 节标题 |
| `〔注〕…〔/注〕` | 双行夹注（小字） |
| `〔批〕…〔/批〕` | 眉批 |
| `〔耳〕…〔/耳〕` | 书耳（版框左上角耳框） |
| `〔标〕…〔/标〕` | 专名线（逐字下加线） |
| `〔圈〕` | 句读圈（不占字格） |
| `〔点〕` | 句读点（不占字格） |
| `〔页〕` | 强制分页 |
| `〔indent:N〕` | 本行缩进 N 字 |

未识别的 `〔…〕` 原样保留为正文，不吞内容；未闭合配对标记会给出行号告警，
并把余下文本作为该标记内容，不静默丢弃。

示例：

```
〔卷〕陈氏族谱卷一
〔章〕始祖世家
盖闻木本水源，人之所自始也。〔注〕据旧谱钞本，始祖讳某。〔/注〕〔圈〕
〔耳〕卷一〔/耳〕
〔页〕
〔卷〕陈氏族谱卷二
〔章〕二世
二世祖讳某，〔标〕配某氏〔/标〕，生子三人。〔点〕
```

## 版式要素（全参数化，预设在 shared/layout/*.json）

| 要素 | guji_classic | plain_modern |
|---|---|---|
| 版框（外框/内框、单双线） | ✓ 双线 | 无 |
| 界行（column grid rules） | ✓ | 无 |
| 版心（书名/卷次/页码） | ✓ | ✓ 书名+页码 |
| 鱼尾（自绘三角+横线） | ✓ | 无 |
| 象鼻（版心上下横线） | ✓ | 无 |
| 书耳（左上角耳框） | ✓ | 无 |
| 夹注（小字双行） | ✓ | ✓ 行内小字 |
| 句读圈点 | ✓ | 现代标点 |
| 专名线 | ✓ | ✓ |
| 竖排右起 | ✓ | ✓ |

版式参数外置在 `shared/layout/*.json`，构建时嵌入二进制；改版式改 JSON
即可，无需改 C++。鱼尾/象鼻/书耳的 SVG 几何为本项目自行设计（据古籍版本学
通识的公版形制），不描摹任何商业软件的素材。

## 合规说明

标记符号集（中文全角 〔〕）与实现均为本项目自研，只借鉴「标记与正文同处
一地、改字即重排」这一功能思想，不采用墨韵/易籍/亦句/GujiStudio 的具体
符号定义、UI 或美术素材。详见 `docs/四款古籍排版软件功能借鉴调研-2026-11-23.md`。
