# GUI 界面重构：文件选择、去控制台、左侧导航（2026-11-23）

## 结论

针对主人三点反馈逐项处理：**① 打开库可点选文件**（内置文件浏览器，跨平台零依赖）；**② Windows 不再弹控制台黑框**（WIN32 子系统 + WinMain）；**③ 15 个浮动面板迷宫 → 左侧导航栏 + 布局预设**（默认只开 4 个核心面板，中央 Dockspace 保留拖拽联动）。GUI 无头测试 **29 用例 / 372 断言全过**。

## 一、三种界面方案评估

| 方案 | 做法 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| A 纯树状导航 | 左侧树，一次中央显示一个面板 | 清爽 | 丢失多面板联动（树+人物卡+表格同时看） | 否 |
| **B 多栏 Dock + 左侧导航** | 左侧固定导航栏按五条工作流分组，点击切换中央面板；一键布局预设 | 兼顾清爽与联动；分组即规划文档的工作流 | 需改默认打开逻辑 | **采用** |
| C 纯 Tab 页 | 顶部标签页 | 简单 | 面板一多标签爆炸，仍丢联动 | 否 |

## 二、文件选择对话框

- 原状：只能手输路径。
- 新增 `gui/file_browser.{hpp,cpp}`（纯 C++，无 ImGui 依赖，可无头测试）：目录浏览、`.db` 大小写不敏感过滤、目录优先排序、相对路径规范化。
- 打开库弹窗：显示当前目录、↑上级、刷新、文件列表（目录可进入、`.db` 可单击/双击选中填路径），保留手输路径入口。
- 跨平台只用 `std::filesystem`，**不调外部程序、不引新依赖**。
- 实测：`.db`/`.DB` 均列出、`.txt` 过滤、子目录可进入、相对路径解析正确。

注意：ImGui 的 `OpenPopup` 必须与 `BeginPopupModal` 在同层级——沿用此前修正（都在 dockspace 顶层），否则弹窗不出现。

## 三、去控制台窗口

- `add_executable(genealogy-gui WIN32 ...)`：Windows 下链接 `/subsystem:windows`。
- `main.cpp` 抽出 `gui_main(argc, argv)`；Windows 新增 `wWinMain`，用 `GetCommandLineW` + `CommandLineToArgvW` 取 UTF-8 参数（与 CLI 的 `wmain` 同口径）；其他平台仍走 `main`。
- `windows.h`/`shellapi.h` 必须在 `GLFW/glfw3.h` **之前** include，否则 `APIENTRY` 宏重定义警告。
- 验证：读 PE header 的 Subsystem = **2（GUI）**，不再是 3（Console）；`--headless-check` 退出码仍为 0（CI 只看退出码，不看 stdout）。

## 四、左侧导航栏与布局预设

- 新增 `gui/navigation.{hpp,cpp}`（无头可测）：面板索引常量、五组工作流（录入/查阅/管理/排版 + 系统在菜单）、四种布局预设（查阅/录入/管理/排版）+「全部」。
- 左侧固定侧栏（210px，可折叠到 40px）：分组树，点击组展开该组面板项，点项打开/聚焦；底部一键布局预设按钮。
- **默认只开 4 个核心面板**（人物卡/世系表/树/检索），其余按需打开——彻底解决 15 个面板一屏浮动的问题。
- `DockSpaceOverViewport` 改为手工 `DockSpace` 在侧栏右侧区域（侧栏宽 + 菜单栏高 + 状态栏高 的剩余区），避免 dock 窗口盖住导航栏；中央仍可自由拖拽分栏联动。

## 五、验证

| 项目 | 结果 |
|---|---|
| 编译 | BUILD=0 |
| GUI 测试 | **29 用例 / 372 断言全过**（新增 2 例：文件浏览器、导航栏数据层） |
| core/cli 测试、e2e、演练、许可、GUI 无头 | 全过；e2e 77/77 |
| Windows PE 子系统 | 2（GUI），黑框消除 |
| 跨平台预检 | MinGW GCC 16.2 对 4 个改动 TU `-fsyntax-only` 全过 |

开发踩坑：`std::filesystem::path` 没有 `is_directory()` 成员（须用 `std::filesystem::is_directory(p, ec)`）；`CommandLineToArgvW` 需 `<shellapi.h>`；navigation.cpp 须加入两个 CMake target（否则链接未定义）。

## 六、边界

- **本环境无显示服务器，无法目视验证侧栏渲染与 dock 布局**；仅验证了编译、数据层单测、headless 退出码与 PE 子系统。需主人在有桌面的机器上目视确认侧栏未被遮挡、布局预设切换符合预期。
- 文件浏览器是内置实现，不是操作系统原生对话框（无最近文件、收藏夹等系统特性）；但换来跨平台一致与零依赖。
- 布局预设只切换面板开关，不保存用户自定义 dock 排列（ImGui 的 ini 持久化未接）。
- 侧栏折叠状态、当前分组不持久化，重启回默认。
- 本记录对应改动尚未提交。
