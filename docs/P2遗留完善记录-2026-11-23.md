# P2 遗留六项完善（2026-11-23）

## 结论

**六项遗留全部修复**：① UTF-8 根治（共用码点工具）；② 夹注跨页续排（页布局引擎）；③ 字形合并（万级元素数降到列数级）；④ 专业复刻精度（多形制鱼尾/双象鼻/栏线组合/装订线）；⑤ `book_html` 与版式管线整合（`--use-layout`）；⑥ 逐字切字非法 UTF-8 随①根治。core 159 用例 / 993,512 断言。全门禁通过。

## 一、UTF-8 根治（原两项补丁升级）

原 `substr(open+1)` 与逐 `char` 切字是两个分散补丁。本轮：
- `core/io/markup.cpp`：标记字节长度从共用 `genealogy::utf8_chars()` 推导（`open_len`/`close_len`），**不再硬编码 3**。
- `core/io/layout_svg.cpp`：删除本地手写 `utf8_chars` 副本，统一用 `genealogy::utf8_chars()` 返回 `string_view`，`esc()` 相应改为接 `string_view`。
- 两处根因同源：`〔〕` 是 UTF-8 三字节，逐字节切会丢首字节/切出非法序列。现在只有一份实现。

## 二、夹注跨页续排（新增页布局引擎）

新增 `core/io/page_layout.cpp`：
- `paginate_content()`：把标记节点流按页容量分配，夹注按 `note_chars_per_cell` 折抵格数。
- 夹注超长时按剩余格数切分，余下内容进入下一页，并插入 `MarkupKind::Continuation` 节点「（注续）」红字提示。
- `〔页〕` 强制分页优先于容量；`capacity=0` 表示不限制。
- 3 个测试：短文本不分页、30 段夹注跨页且字符不丢、强制分页。

## 三、字形合并优化

`layout_svg.cpp` 正文渲染从「一个字一个 `<text>`」改为**列缓冲 + Run 合并**：
- `Column` 累积字符，样式相同连续字符合成一个 `Run`；
- 列满换列，输出时每 Run 一个 `<text writing-mode='vertical-rl'>`；
- 测试：2000 字 → `<text>` 元素 < 100 个（原为 2000+）。

## 四、专业级复刻精度

`shared/layout/guji_classic.json` 扩展并由渲染器实读：
- **鱼尾五形制**：single_black / double_black / flower / cloud / line，自行设计的 SVG 几何；
- **象鼻单/双线**：`line_count` 参数控制；
- **栏线四边独立**：`side_rules.{top,bottom,left,right}` 支持 double/single/none，可实现左右双边、上下单边；
- **装订线**：`binding.holes` 4/6/8 眼，书口侧虚线+孔；
- 版心卷次对称、天头地脚倍率、鱼尾可用形制列表等参数。

## 五、book_html 与版式管线整合

`genea io export book --use-layout [--layout-preset guji_classic]`：
- 从数据库人物生成标记节点（世代行 + 行传作夹注），走同一份 `paginate_content` 与 `render_layout_page`；
- 输出 SVG 序列（多页 `foo-pN.svg`），JSON 返回页数与 `continued_notes`；
- 旧 HTML 路径不变，两条路径共享页布局/版式引擎，不再各写一套。

实测：11 人测试库导出 1 页 SVG，栏线/鱼尾/竖排合并全部命中。

## 边界

- 夹注续排按「码点容量」切分，不按视觉行高精确计算——极长夹注的分页点是近似的。
- 字形合并按列合并，跨列的专名线会断成多段（读起来仍是连续下划线）。
- 鱼尾/象鼻/装订线为公版形制的简化几何表达，非专业古籍复刻级精度；五形制已备但预设默认仍用单黑鱼尾。
- 本记录对应改动尚未提交。
