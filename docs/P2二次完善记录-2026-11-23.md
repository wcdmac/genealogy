# P2 二次完善：三处边界根治（2026-11-23）

## 结论

**三处遗留边界全部根治**：① 夹注续排从「码点容量近似」改为共享几何模型的精确分页；② 专名线改为独立覆盖层，跨列连续不断裂；③ 默认双黑鱼尾、装订线几何精修。core 161 用例 / 993,520 断言。全门禁通过。

## 一、夹注续排：共享几何模型（根治近似分页）

**根因**：过去分页器用抽象 `capacity=600` 格切页，渲染器用自己的列/行几何（`col_capacity`、`col_left_limit`），两套模型不一致，续页点是近似值。且渲染器 `Column.rows` 混用了「像素」与「行数」单位。

**修法**：新增 `core/include/genealogy/io/layout_geometry.hpp`，定义：
- `LayoutGeometry`：版框像素几何（frame_l/r/t/b、center、body_step、note_step、col_gap）；
- `half_rows_per_column()` / `columns_per_page()` / `column_x()` / `row_y()` 派生函数；
- `TextCursor`：以「半行」为统一单位的字符游标（正文1字=2半行，夹注双行小字1字=1半行），换列时夹注补齐整行避免两字一格被拆列。

分页器 `paginate_content` 与渲染器 `render_layout_page` **共用同一游标**：分页点就是渲染时的真实换页点。新增 `use_geometry` 开关（false 时只按〔页〕标记分页）。

**验证**：小版框（2列×3行=6格）测试——8 字正文精确分为 6+2 两页；20 字夹注跨页零丢失、续接标记就位。

## 二、专名线跨列连续

**根因**：过去 `em` 样式靠每个 `<text>` 的 `text-decoration='underline'`，跨列时下划线断在列边界。

**修法**：`em` 字符不再用 text-decoration，而是在 `emit_char` 时记录逻辑位置序列 `em_marks`；所有文字输出后，画一条独立 `<path>` 覆盖层：每字符画短竖线，相邻 mark 跨列时补一条折线连接上下列。专名线按**逻辑顺序**连续，不受列缓冲分段影响。

**验证**：100 字专名跨列，覆盖层 path 的 M 命令数 > 100（每字一段 + 跨列段）；无 text-decoration 残留。

## 三、复刻精度：默认双黑鱼尾 + 精修

- `guji_classic.json`：`yuwei.style` 改 `double_black`、`count` 改 2（上下双鱼尾）；新增 `upper_y_ratio`/`lower_y_ratio` 控制鱼尾纵向位置，`stroke_width` 控制线宽。
- 装订线：`hole_diameter` 2.5mm、`spacing_ratio` 0.22、`thread_color` 参数化；渲染器实读 `thread_color` 画孔与穿线。
- 测试：默认双黑鱼尾产出 2 个三角 path；装订孔 4 个；孔色参数生效。

开发中踩坑：测试统计中文字符用 `.text.size()` 是**字节数**（3 字节/字），须用 `utf8_chars().size()` 取码点数；Catch2 `CHECK(a != x || b != y)` 宏解析失败，须先提取 bool 变量；`finalize_active` 须重置 `active` 索引否则跨页索引失效。

## 边界

- 几何模型用 19px 正文行高、12px 夹注行高，按字符数推进——仍是离散近似，非字体度量级（不同字体/字号的实际字面框未测）。
- 专名线覆盖层按字符中心画短竖线，跨列折线是简化连接；极宽字距下需微调 `mark_dx`（当前 14px）。
- 双黑鱼尾为上下两个自绘三角，形制仍是公版通识的简化表达。
