# P1 遗留三项完善（2026-11-23）

## 结论

**P1 的三处遗留全部修复**：① 欧/苏式改为物理分页（每页独立 SVG，苏式跨页重叠一世）；② 五服改为九族严格矩阵（九族纵轴 × 五服横轴，服等逐对由外置规则表计算）；③ 同层节点防重叠 + 万级节点性能回归。core 测试升至 144 用例 / 993,426 断言。

## 一、物理分页

根因：`ChartResult` 只有单个 `svg` 字段，分页无从表达。

修法：
- `ChartResult` 新增 `pages`（`ChartPage` 含独立 SVG、起止世代、是否重叠）；`svg` 保留为第一页（向后兼容）。
- 新增 `slice_layout()`：按世代区间裁切布局、重映射边索引、y 归零。
- 分页算法：欧式每页 `page_size` 世不重叠；苏式 `step = page_size - 1`，下一页首世 = 上页末世。
- CLI 多页输出 `foo.svg` → `foo-p1.svg` / `foo-p2.svg`，JSON 返回 `files[]` 含每页世代区间与重叠标记。
- 世代显示 +1 映射（内部布局 0-based，用户看"第 N 世"）。

验证：11 世 5 页设置下，欧式 pages=[1–5,6–10,11]，苏式 pages=[1–5,5–9,9–11]（每页首世重叠）。CLI 实测 `--page-size 2`：欧式 1-2/3-3，苏式 1-2/2-3 [overlap]。

## 二、九族五服严格矩阵

根因：原 Wufu 复用 descendant 骨架 + CLI 脚注，不是矩阵。

修法：新增 `core/io/wufu_matrix.cpp`：
- 纵轴九族：generation_gap -4..+4（高祖辈…己身…玄孙辈），由**关系路径** `generation_gap()` 推出，不用世代序号差（项目铁律）。
- 横轴五服：斩衰/齐衰/大功/小功/缌麻（袒免/无服不入格）。
- 遍历全图，逐对 `find_relationship` + `compute_mourning_degree`（ming_qing 外置规则表），按世代差与服等填格，每格显示人数与最多 4 个代表姓名。
- 无效焦点报 NotFound，不静默出空矩阵。

验证：测试库实测命中 9 人、5 个有服格，九族五行与五服五列标签齐全。

## 三、布局质量与万级压测

修复的真实缺陷：配偶节点 x 恒为 0，与同层首个子女重叠。配偶现与子女同层统一参与 x 分配，每个节点独占 `kNodeW+kGapX`。

新增两个测试：
- **同层不重叠**：解析 SVG transform 坐标，同 y 节点两两间距 ≥ 96px。
- **万级性能回归**：1 始祖 + 10000 子女，depth=2 渲染，阈值 <10 秒（防数量级退化）。

开发中修复的编译问题：`const int col/gap` 初始化（MSVC C2737）、缺 relationship.hpp/mourning.hpp include、测试期望未随体例变更更新（Wufu 不走通用 SVG 交互）。

## 边界

- 分页是"按世代区间裁切"——若某代跨页边界，该代整体在一页，不会把同一代拆到两页。
- 五服矩阵显示"每格人数 + 代表姓名（最多 4 个）"，不是把每个人名都画进格子——万级谱全量列出不可读。
- 万级测试阈值为 10 秒宽松上限，仅防数量级退化；未做精细性能调优（当前瓶颈是 `branch_key` 上溯父链，O(n·depth)）。
