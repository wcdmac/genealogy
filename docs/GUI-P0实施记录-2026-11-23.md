# GUI P0 实施记录：录入·关系·排版入口（2026-11-23）

## 结论

**GUI 从"只能看和改既有"升级为"可完整录入、建关系、查阅、排版"。** P0 四模块落地：新建人物面板、关系快捷录入、排版导出面板（三类型）、导航快捷键。GUI 无头测试 17 用例 / 188 断言，全门禁通过。

## 一、新建人物面板（`new_person_panel`）

- 数据层（`new_person_panel_state.cpp`，无 ImGui 依赖可无头测）走 `PersonService::create_person`（ADR-1）。
- **智能预填**（借鉴 Heredis）：姓氏随焦点人物、世代默认下一代、焦点为男性时作为父亲候选。
- 日期双模：数字走 `from_iso`、含汉字走 `from_raw`——老谱原文「同治三年四月初四」自动认年号（实测）。
- 创建后自动成为全局焦点；姓氏/世代预填保留便于连续录入同一支。

## 二、关系快捷录入（借鉴 Gramps 关系按钮）

- 人物卡关系链区新增四个按钮：`+父亲` `+母亲` `+配偶` `+子女`。
- 点击写入 `AppState.new_relation_kind` / `new_relation_anchor`，自动打开新建面板并预填：
  - `+子女`：按锚点性别自动填 father_id 或 mother_id；
  - 其他类型预填姓氏，避免从零录入。
- 创建后清空待建关系状态。

## 三、排版导出面板（`export_panel`）

三种产出全部接通 core 管线（不在 GUI 重写排版）：
- **古籍版式 SVG**：标记文本 → `io::render_layout_page`，可选预设与 `--body-size` 字号覆盖；
- **世系图 SVG**：全量人物+结合建 `PersonGraph` → `io::render_chart_svg`，六种体例可选；
- **谱书 HTML**：`BookService` + `io::render_book_html`（字体随包内嵌）。

「从当前人物生成」按钮把焦点人物与子女自动转成标记文本（行传→夹注）。生成后可预览字节数、导出文件。

## 四、导航快捷键

Ctrl+N 新建人物（菜单项同步），Ctrl+O 开库（已有）；新建人物菜单与关系快捷按钮共用同一面板入口。

## 六、边界

- 关系快捷已闭环：+子女自动填 father_id/mother_id；+配偶创建后自动建 Union；
  +父亲/+母亲创建后回填焦点的 father_id/mother_id（带 rev 乐观锁）。
- 排版面板只显示产物字节数，未做 SVG 内嵌预览（需引入 SVG 光栅化依赖，违反依赖纪律）。
