# P0 实施记录：出版管线与随包字体（2026-11-23）

## 结论

**P0 两项全部落地并经全量验证**：① 随包完整思源字体（全库自带，无子集化）；② `genea io export book` 出版管线（三版式 × A4/16 开 × 纵横向，自包含 HTML，浏览器打印 PDF）。core 测试升至 137 用例 / 993,317 断言，全门禁绿，CPack 包内确认含字体。

## 一、字体：全库自带（按主人要求纠正方向）

初始尝试子集化（3873 字、约 6MB），但子集化本身会造成缺字，与"全库自带"要求相悖，**已删除并改为完整字体**：

| 文件 | 大小 | 覆盖 |
|---|---|---|
| `assets/fonts/SourceHanSansSC-Regular.otf` | 15.8MB | 44,853 字形（基本汉字 20,992 + 扩展区约 2,594） |
| `assets/fonts/SourceHanSansSC-Bold.otf` | 16.2MB | 同上 |
| `assets/fonts/SourceHanSerifSC-Regular.otf` | 23.4MB | 44,779 字形（基本汉字 20,992 + 扩展区约 2,531） |

- 来源：Adobe 官方 release 2.005R / 2.003R 的 SC 地区子集 OTF，**未经修改**，保留原 RFN 名"Source"（OFL 条件 3 不触发）。
- OFL 1.1 全文随附 `OFL-SourceHanSans.txt` / `OFL-SourceHanSerif.txt`；来源与覆盖边界见 `assets/fonts/README.md`。
- `gui/src/font.cpp`：随包字体优先（Full glyph ranges 覆盖生僻字），系统字体降为兜底（Common ranges 控图集）；跨平台定位 exe 同目录 `fonts/` → `share/genealogy/fonts/` → 开发期 `assets/fonts/`。Windows 用 `GetModuleFileNameW`，macOS 用 `_NSGetExecutablePath`，Linux 用 `/proc/self/exe`。
- `CMakeLists.txt`：`install(DIRECTORY assets/fonts/ DESTINATION bin/fonts)`——CPack 实测 ZIP 包含 3 个 OTF + 2 份 OFL + README。
- `license_check.py`：新增 `check_bundled_fonts()`——有字体无 OFL/README 即卡点失败；白名单登记两项（12 项）。

**覆盖边界（诚实）**：单款思源 SC 覆盖约 4.5 万字形，不是 Unicode 16.0 全部 98,682 汉字；Ext C 以后不在其中，运行时由平台回退链兜底。这是宽松许可字体的实际天花板。

## 二、出版管线

新增 `core/include/genealogy/io/book_html.hpp` + `core/src/io/book_html.cpp`：
- 纯函数 `render_book_html(Options)` → HTML 字符串，core 无 UI/网络依赖（ADR-1）。
- 三版式：register（世系表，7 列表格）/ genealogy（世系谱，竖排分世代）/ biography（行传，含 `biography` 正文）。
- A4（210×297mm）/ 16 开（185×260mm）、纵横向、`@page` 页眉书名页脚页码、封面与派语竖排（`writing-mode:vertical-rl`）。
- 字体以 base64 内嵌完整思源宋体，产物单文件约 32MB 离线可用；`--no-embed-fonts` 出轻量版约 2KB。
- HTML 转义（防 `<script>` 注入）、标题空值回退、空 persons 指针安全。

CLI `genea io export book`：`--template/--paper/--landscape/--no-embed-fonts/--font-dir/--out`，接入 `cmd_io` 分派与帮助文本。

**开发中修复的真实缺陷**：`by_generation(opt.persons ? *opt.persons : std::vector<Person>{})` 的条件表达式构造临时 vector，`const&` 绑定后悬垂——字体嵌入路径触发段错误（RC=139）。改为具名空 vector 后消失。这是本轮最有价值的发现。

## 四、边界

- 打印需用户在浏览器 Ctrl+P 另存 PDF，非静默批量——这是 P0 刻意的零依赖取舍；静默批量属 P3（PDFium）。
- 生僻字覆盖止于思源 SC 的字形上限；极冷僻字由系统字体回退，不保证印刷一致。
- 出版 HTML 内嵌 23MB 字体导致 32MB 文件；若网络/磁盘受限可用 `--no-embed-fonts`。
